# Avatar assets

Place your portrait here as `avatar.jpg`.

## Recommended

- Aspect ratio: **3:4**
- Resolution: about **800×1000** px
- Format: JPG or WebP (if WebP, update the `src` in `index.html`)
- Framing: head-and-shoulders, face centered, soft background

If the file is missing or fails to load, the template shows brand initials automatically.

The included `avatar.jpg` is a **sample placeholder** — replace it before publishing.
