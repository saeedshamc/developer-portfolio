۰۱ — درباره

پل زدن میان زبان، چیدمان و منطق.

من یک توسعه‌دهنده فول‌استک با بیش از ۶ سال تجربه در ساخت اپلیکیشن‌های وب برای مخاطبان فارسی و انگلیسی هستم. به ریتم تایپوگرافی، CSS دو‌جهته و APIهای مقیاس‌پذیر اهمیت می‌دهم.

از داشبوردهای SaaS تا جریان‌های فروشگاهی، React، Node.js و i18n آگاهانه را ترکیب می‌کنم تا هر زبان بومی احساس شود — نه ترجمه‌ای پس از فکر.

  • تمرکز رابط RTL و محصولات دوزبانه
  • فناوری React · Node.js · TypeScript · PostgreSQL
  • موقعیت تهران · دورکاری جهانی
