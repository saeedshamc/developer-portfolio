How to use

  1. Open a template folder and preview index.html.
  2. Replace assets/avatar.jpg with your portrait (3:4 works best).
  3. Edit name, role, projects, and links in index.html.
  4. Deploy the folder to any static host (GitHub Pages, Netlify, Vercel…).

Photo tip

Recommended: JPG/WebP, about 800×1000 px, face centered, soft background. If missing, initials fallback shows automatically.
